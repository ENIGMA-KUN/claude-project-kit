## Architecture (4)

- [API layer](architecture/api-layer.md): FastAPI routers: validate input with Pydantic, call a service, shape the response. No business logic, no database access.
- [Billing service](architecture/billing-service.md): Business rules for invoices, proration and refunds. Pure functions over repository calls; the only place money is computed.
- [Build system and tooling](architecture/build-system.md): uv manages Python, the venv and dependencies; ruff lints; pytest runs tests.
- [Database layer](architecture/database-layer.md): SQLAlchemy models and repository functions over PostgreSQL; migrations with Alembic.

## Decision (2)

- [Three-layer architecture](decisions/three-layer-architecture.md): Routes call services, services call repositories. Each layer only talks to the one below it.
- [UUIDs as public ids](decisions/uuid-public-ids.md): APIs expose a public_id UUID, never the integer primary key.

## Lesson (3)

- [Never query the database from routes](lessons/never-query-db-from-routes.md): Never import app.db in app/api; add or reuse a service function instead.
