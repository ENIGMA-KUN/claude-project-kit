# Kit feedback

Notes from projects about what the kit template should do better. `/kit-init` and `/curate` append here when `kit_home` in a project's `.claude/kit/config.json` points to this folder.

Review this file when you next improve the kit: change the template, run `python tests/smoke_test.py`, then re-run the installer on your projects.

Format: `- <date> <project>: <what did not fit> -> <suggested change>`
