# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, critique ideas rather than people, and keep discussions about the work. Harassment, personal attacks, and publishing someone's private information are not accepted in issues, pull requests, discussions or any other project space.

## Reporting

If someone's behaviour concerns you, report it privately to the maintainer through GitHub: use the "Report content" option on the comment or issue, or open a private security advisory on this repository if the matter is sensitive. Reports are handled confidentially.

## Enforcement

The maintainer may edit or remove comments, close issues or pull requests, and block contributors who break this code, following the enforcement guidelines of the Contributor Covenant 2.1: correction, warning, temporary ban, permanent ban, depending on the impact.
